# Hive

A collection of Go exercises and small command-line projects built as practice and portfolio pieces from 0 to koodWordle in only 19 days of Sprint Selection at Hive Helsinki.

## Structure

- `cypher/` – terminal-based encryption tool
- `koodWordle/` – Wordle-style game with persistent stats
- `weatherStation/` – weather station data parser/formatter
- `sprint/` – short Go exercises and coding drills

## Notes

This repository is meant to showcase learning progress and small projects rather than production-ready software. Some folders are intentionally minimal learning exercises and may not be polished UI or app experiences.

## Run locally

```bash
go test ./...
```

From each project directory, or use Go workspaces as needed.
